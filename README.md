# Social Event Management

Live Site: https://social-event-management-red.vercel.app/
Server side code: 

A simple website to create, share and join social events with friends and communities.

## Features

- **User Authentication** – Sign up and sign in securely with Better Auth.
- **Create Events** – Users can create events with title, date, time, location and description.
- **Join Events** – Browse upcoming events and join any event with a single click.
- **Manage Events** – Edit or delete your own events from your dashboard.
- **My Joined Events** – See all the events you joined and cancel attendance anytime.
- **Home Page Sections** – Hero banner, featured events, recent events, gallery and newsletter.
- **Responsive Design** – Works smoothly on mobile, tablet and desktop.
- **Dark / Light Theme** – Toggle between dark and light mode.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui + Radix components
- Better Auth + MongoDB
- Sonner (toasts)

## Getting Started

1. Clone the repo
2. Install dependencies

```bash
npm install
```

3. Create a `.env` file with your MongoDB and auth credentials
4. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
